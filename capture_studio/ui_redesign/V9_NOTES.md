# Capture Studio v9 说明 (0.9 / 基于 v8 复制)

## 修复的 v7 遗留问题
1. 模板 output：模板不再保存/覆盖日期子目录；套用模板只对单次录制生效（output_once），设置里的输出目录不被改写（templates.base_output）。
2. 回放：refresh 不再清空回放标签；回放标签显示 "回放 · i/n · m:ss / m:ss"。
3. 预计大小：去掉拍脑袋系数，按 精确(YUYV 2B/px)/码率/历史实测/上限 四种依据估算并在提示里标注依据。
4. 温度阈值：优先板子 thermal trip，其次文档值 (RPi 80/85, K26 DS987 90/100)，否则通用 80/90 并标"通用"。
5. USB 带宽检查改用源原始速率；会话回顾记录 codec/source_format。

## 新功能
- 多摄像头自动选择：上次使用 → VID:PID → 唯一 UVC；PC 页显示选择原因胶囊，手动选择即覆盖并记住。
- 未连接时空白区填真实数据：开发板页"快速连接"面板（PC 摄像头/串口/USB/外设计数、连接向导、扫描局域网）；外设页离线回退显示本机外设；数据卡显示磁盘用量和本地会话。
- i18n：全部新字符串中英覆盖，标题大小写统一，无乱码；英文无截断（smoke 逐页检查）。
- 视觉：Apple 风格卡片(14px 圆角、细边框、柔和阴影)、胶囊状态、导航选中态、8px 控件圆角、24/16 间距；深色主题同步。
- 隐藏页水平 Ignored，修复真实字体下右侧面板被裁切。
- 打包脚本对包名无关（launcher/connect_kv260/build_portable/cmd）。

## 测试

- 测试页"画面"标签下方在未连接时仍有留白（加入数据卡会让 1280×800 下高度溢出，已回退）。
- K26/RPi 温度阈值来自文档，未读到 trip 时生效。
- 实屏 DPR 1.25（125%，逻辑 2048×1152，96 DPI），offscreen 字体与实屏不同。
