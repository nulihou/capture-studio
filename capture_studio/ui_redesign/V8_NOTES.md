# capture_studio_ui_v8

在 v7 上补上真机测试里缺的识别和选择。v7 及更早的目录没有改动。

启动：`cd E:\yolo26_FPGA_tiny` 然后 `python -m capture_studio_ui_v8`

## 自动找开发板

- `ipconfig` / `arp` 按系统编码读取。中文 Windows 不再把“网关”读坏，从而扫不到网段。
- 跳过 VMware、Hyper-V、WSL、VPN，以及 Clash/Meta 用的 `198.18.0.0/15`。
- 只有发出 `SSH-` 标识的主机才算开发板。只接通、没有标识的地址不再列入向导。
- `kria.local` 如果被解析进上述虚假地址，直接忽略。

## 摄像头

- 电脑上的采集列表显示 `名称 · VID:PID`。两只同名摄像头改用各自的 DirectShow 设备路径，不再叠成一项。
- 开发板上有多只摄像头、又对不上记下的序号时，连接仍然成功，列表里选一只再开始。不再因为无法猜测而整次连接失败。
- 板端录制仍使用同一套 V4L2 / GStreamer 代理，Jetson、树莓派等只要能 SSH 并有 `/dev/videoN` 就走这条路径。HHW001 的原生快路径只在那只摄像头、MJPEG、640×480 时使用。
- 连接时如果 8765 上已有旧的采集代理、令牌不在当前目录，会先确认它没在录制，再换上这一版（带 `/formats`）。正在录制时不会替换。

## 预览

单帧上限仍是 8 MB。超过这个大小的数据块在读取正文前拒绝。旧测试用 2 MB 当上限，和实际上限不一致。
